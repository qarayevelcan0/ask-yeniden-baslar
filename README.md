
# ❤️ Aşk yeniden başlar

Online multiplayer şüşə oyunu.

## Texnologiyalar
- Next.js
- React
- TypeScript
- CSS

## Başlatmaq

```bash
npm install
npm run dev
```

## Layihənin məqsədi

Android, iPhone və kompüter brauzerlərində işləyən
onlayn oyun platforması yaratmaq.

## Planlaşdırılan sistemlər

- Oyun otaqları və multiplayer
- İstifadəçi hesabları və profillər
- Dostlar və mesajlaşma
- Gold və Diamond
- Hədiyyələr və VIP
- Admin və moderator paneli
- Azərbaycan, Türk, Rus və İngilis dilləri
